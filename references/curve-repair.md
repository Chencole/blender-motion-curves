# 曲线诊断与修正方法

研究日期：2026-10-08。以下动作修正策略是基于 Blender 工具语义和运动学的工作方法，不是模型质量承诺。官方工具出处见 [API 与来源](blender-api.md#官方来源)。

## 1. 先分清“曲线”表示什么

F-Curve 把一个数值通道映射到时间：位置、旋转分量、控制器参数或约束权重等。显示的是局部输入；父级、IK、约束、NLA 和根运动都会改变最终结果。

| 症状 | 先检查 | 适合的方法 | 不能用来替代的工作 |
|---|---|---|---|
| 旋转曲线突然跳约 360° | Euler XYZ、旋转顺序、实际姿态是否连续 | Euler Filter，随后逐帧和子帧复核 | 真实的 IK 翻肘、万向锁姿态设计 |
| Quaternion 四条曲线一起反号 | 单位长度、相邻点积、方向是否相同 | 符号连续化，再做旋转空间处理 | 把四条分量各自当位置曲线平滑 |
| 密集采样的小幅高频抖动 | 原视频、控制器噪声、武器端点放大 | 局部弱 Gaussian 或 Butterworth | 持续错误的腕部方向、错误握持 |
| 出招像匀速搬手、命中没力度 | 动作事件、速度峰值位置 | 分段时间重映射；必要时少量路径偏移 | 全段强平滑、统一慢放 |
| 接触前后手离开剑柄 | 武器父级、IK 目标、约束 influence | 修目标/权重曲线并保持几何接触 | 仅平滑手腕 Euler |
| 两段间弹回起点 | root 空间、起止变换、NLA 混合 | 根位移对齐、过渡区修正 | 把真正的移动轨迹全部清零 |
| 减键后脚滑/刀尖漂 | 接触区、世界空间端点误差 | 回退问题区间，保留接触锚点 | 只降低单条曲线的数值误差 |

## 2. 建立可比较的测量

使用 `fps / fps_base` 作为每秒帧数。`dt = Δframe / 实际帧率`；位置换算为同一空间和单位。内点可用中心差分估计速度，端点用单边差分。导数放大噪声，不能看到尖峰就删除。

旋转角速度必须从方向变化估计，不能对 Euler 三分量各求导再当真实角速度。相邻单位四元数的最短角距离：

```text
dot = clamp(abs(q_prev · q_next), 0, 1)
angle = 2 * acos(dot)
angular_speed = angle / dt              # rad/s
```

这是相邻采样的最短角距离；超过 180° 的真实快速旋转会发生采样歧义，应增加采样密度。先把四元数归一化；若相邻点积小于零，将后一个的四分量同时取反以保持表示连续。不能为得到“平滑曲线”而改变有意的连续旋转圈数。

至少跟踪需要修正部位及其影响：pelvis/root、手腕、前臂、支撑脚、武器柄与刀尖。长度与骨架比例相关；不硬编码通用厘米阈值。检查世界空间接触残差，例如手部握持点与剑柄目标的距离/方向差、脚底相对地面的滑移。

曲线样本来自 `fc.evaluate(action_frame)`；最终姿态要在正确场景帧通过依赖图求值。两者不能混为一谈。查看子帧，捕捉整数帧间的过冲和翻转。

## 3. 选择局部修正方法

### 表示连续化

Euler Filter 要把同一对象/骨骼的 XYZ 旋转曲线成组处理。它尝试寻找等价且相容的 Euler 表示，并修正 360° 绕回；不是自动消除万向锁的工具。Quaternion 不适用这个滤镜。改变旋转模式需要完整转换/重烘焙的规划，不能直接切菜单后继续修改旧通道。[官方 Euler 算法说明](https://developer.blender.org/docs/release_notes/2.92/animation_rigging/#euler-filter)

### 局部平滑

- Gaussian operator 改写所选关键帧；modifier 是可撤回的求值层。窗口以帧表达，先换算成时间。
- Butterworth 的截止频率、阶数及边界混合共同影响结果。急变附近可能产生波纹；低截止频率不等于更好。
- 先选一个非接触噪声段，使用弱强度试验。固定区间外姿态并给边界过渡，检查邻近帧与子帧。
- 不把攻击速度峰值、招架碰撞时的短停顿或有意的回弹都当噪声。
- 测量握持/脚锁是否变坏。滤波器没有自动保护世界空间接触的能力。

### 低频偏移曲线

持续一段的局部误差可用少数偏移锚点修改，而不逐帧手动重新摆姿势。平移示意：

```text
p_new(t) = p_original(t) + w(t) * delta_p(t)
```

`delta_p` 用少量有目的的控制点定义；`w` 在区间边缘为 0 且一阶导数为 0。可用 `s(u)=3u²-2u³` 分别构造进入和退出窗口，中间保留平台。进入/退出区间必须明确，不能把一个只由 0 升到 1 的 smoothstep 当成两端归零窗口。

旋转不能简单在 Quaternion 四个分量上加偏移。可构造 `q_delta(t)=slerp(identity, delta_rotation(t), w(t))` 后复合。局部偏移常用 `q_original * q_delta`，父空间偏移常用 `q_delta * q_original`；实际乘法顺序由坐标约定决定，先验证单个样本。Euler 局部小偏移也须避开绕回和奇异点。

若目标由 IK 驱动，偏移应该施加在 IK target/pole 或可编辑控制器上。双手持一把剑时，先决定统一的武器/主手驱动关系，再让从手保持剑柄目标；避免“剑跟手、手又跟剑”的约束循环。手指需要与剑柄尺寸匹配的握持姿态及接触检查，平滑不能凭空求得正确握持。

### 分段时间重映射

```text
t_source = phi(t_output)
pose_new(t_output) = pose_original(phi(t_output))
v_new = v_original(phi(t_output)) * phi'(t_output)
```

攻击/招架通常要求 `phi` 单调不减。暂停段可有零斜率；若不需要暂停则保持正斜率。任意 Bezier 手柄可能造成时间倒流，应检查整个映射而不只检查锚点次序。

根据原片段定义预备、举剑、挥击、接触、回收等事件，再调整各事件之间的时长。对同一动作相关的 root、身体、武器、握持目标、pole 与约束权重应用同一事件映射，避免剑已到而手还未到。两角色可以各有不同映射，但接触时刻必须对齐。

NLA Playback Scale 大于 1 会延长时长、减慢播放，小于 1 会缩短时长、加速。Animated Strip Time 的曲线值是 Action 帧号，不是播放速度。单纯改变条带末帧可能裁切/延展，并不等于等比变速。Tweak Mode 的时间重映射显示有限，返回完整 NLA 栈复核。[官方 NLA 属性](https://docs.blender.org/manual/uk/5.2/editors/nla/sidebar.html)

### 插值、减键与过渡

Auto Clamped 可减少某些 Bezier 过冲，但可能让局部极值变平。连续加速度插值不保证动作有正确发力。密集逐帧数据的主要问题常在采样值本身。

`Clean` 按冗余判断删键，`Decimate` 按比例或标量偏差简化，两者都不等于去抖。先完成姿态/节奏修正，再试小范围减键。明确保留接触区和事件锚点，检查最终世界空间误差。

连接攻击与招架时，先对齐空间、支撑和事件，再在过渡窗使用位置混合与 Quaternion 旋转混合。混合后的 IK/手脚接触可能改变，应在最终求值后复核。不能用加长 crossfade 掩盖双方姿态、朝向或握剑位置不相容。

## 4. 攻击/招架研究实例（不代表已分析用户文件）

针对“举剑后下劈”和“抬剑招架”两段，先填真实时间，不预设命中发生在第几帧：

| 阶段 | 主要观察 | 可能的最小操作 | 保护目标 |
|---|---|---|---|
| 预备至举剑 | 上臂与躯干是否协调，握持是否持续 | 手腕/握持目标低频偏移；局部轻滤波 | 主动作与双手相对剑柄位置 |
| 挥击加速 | 速度峰值是否接近实际接触 | 统一的分段时间重映射 | 原始刀路、支撑脚与重心 |
| 招架接触 | 两把角色各自持有的剑是否在同一时刻交会 | 对齐事件与目标位置，小范围 IK/控制器修正 | 每个角色仍持原来的一把剑，手不离柄 |
| 碰撞至回收 | 是否僵停、弹回或瞬移 | 局部速度过渡和低频偏移 | 接触之后的合理回弹与根运动 |

先研究各自一小段，再并排/同场景比较。武器空间没对齐时，先报告这个事实；不要只改曲线形状后声称招架已经接上。
