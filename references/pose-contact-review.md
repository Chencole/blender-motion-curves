# 姿态、穿插与局部修正复审

用于人物姿态/接触问题以及没有指定细节的“修这段动作”。只有节奏或曲线表示问题时，不必强加全身接触重建。

## 1. 先选真正的问题

检查原片整段以及能看清问题的两个角度，记录原始姿态和修改范围。将用户诉求变成可验证的目标：

| 用户问题 / 现象 | 必要改动与验收 | 不能当作修复证据 |
|---|---|---|
| 手和前臂交叉、穿模 | 调整手/肘轨迹或约束；检查实际蒙皮手掌、手指与对侧手臂 | 末尾更慢、腕骨分开、曲线更光滑 |
| 双手握同一把剑却离柄 | 校准共同柄轴与各手握点，联合检查肩肘腕、手指、武器 | 只把双手拉开到不碰撞 |
| IK 后肘突然翻侧 | 检查弯曲平面、pole 投影退化与 roll；修连续目标并复核子帧 | 骨长正确、每帧都能碰到目标 |
| 只要求收势慢一些 | 一致调速并保护所指区间；其他姿态缺陷作为独立发现 | 借机改整段刀路、握姿或脚步 |

“保留原动作”通常保护编排、根运动、时序或未涉及部位；不会要求保留导致投诉的错误姿态。不能为了容易量化而主动选择次要问题，再以主要问题“仍存在”的免责声明结束完整修复请求。

## 2. 交叉的证据分层

1. **屏幕投影**：正面呈 X 形不一定真的穿插，手跨过身体中线也可能是有意的斜向持剑。以多视角和实际空间关系确认，不自动禁止所有交叉姿势。
2. **骨骼几何**：世界空间腕位置、双前臂/上臂线段最短距离适合找候选区间；不能代表带厚度的手掌、伸出的手指和衣袖。
3. **实际表面**：读取依赖图求值后的 mesh，变换到同一世界空间。按已核实的骨权重、顶点组或模型分件划分手、前臂、上臂，检查双方手和所有可能碰到的对侧肢体。若蒙皮分区不可信，标为未知并依赖近景复查，不能把缺失分区计作零碰撞。

可用三角形 BVH overlap 辅助检测表面相交，但须记录 epsilon、分区范围与采样帧。零表面交叉不能排除闭合物完全包含在另一个物体内、漏选区域或两次采样之间的碰撞。顶点到表面的最小距离是完整表面距离的上界，不能把它当成保守安全间隙。必要时加体积/有符号距离检查，并用实际近景核对。

先筛查整段，再对疑似区间、修正边界与速度峰增加子帧。检查密度根据运动速度、尺寸和风险选择，不把“90帧”或“半帧”当通用标准。只能声称已检查的范围和精度，不能用零碰撞认证整体自然度。

## 3. 手肘修正的可复用方法与边界

- 使用角色胸部/肩部的局部方向描述左右、上下、前后，先验证坐标与骨名。不在世界 X 上直接固定双手间距；转身后会错。
- 可从保留双腕中点轨迹开始，调整必要的相对位置，再解保持原骨长的两骨链。这只是候选方法：两手同握一物时，间距和朝向应由柄长、掌形与握点决定；双手中点本身错了也需要调整。不要沿用另一角色的厘米数、帧区间或左右手分工。
- 原肘投影到新肩腕轴的垂直平面后，若长度接近零或方向突然反号，逐帧追随它会造成 pole 换侧。采用连续的角色局部 pole 锚点、平行传输或适当的约束，避免硬阈值切换制造新急转。
- 上臂与前臂分别做最短旋转对齐可能改变相对 roll。检查整条链的弯曲平面与局部四元数变化；必要时用已校准的参考平面计算两段旋转，不能只看关节点落在目标上。
- 修改肩肘后，即使腕部局部曲线未动，世界手掌位置、朝向和接触也会改变。再次检查手指对另一前臂、手对手、手对柄。若需改腕或握指，应先做小幅正负试转校准屈曲方向，不能对所有骨头套统一 Euler 角。
- 比较原版和修正版的受影响及保护部位；不把源动作已有的快速挥击误判为新增错误。用实际求值、符号连续的四元数和子帧检查区分急转与表示反号。

## 4. 内部迭代与交付判断

每次候选修正保留一行记录：`目标 → 改动 → 原缺陷是否仍在 → 新风险 → 下一步`。

- 骨段分开但手掌仍穿前臂：候选失败，继续改姿态/接触；不要直接输出成品。
- 穿插消除但新出现肘部跳转：候选失败，修弯曲平面并回归原穿插区间。
- 两项通过后：检查整段正常速度及必要慢放；核对保护部位和动作意图，保存/重新载入，若输出 FBX 则重新导入复核。

授权明确时，这些迭代在同一请求内完成。若仅有截图或确实缺少必要资产，说明尚不能验证什么；若多次候选仍不能满足主要目标，重新诊断或报告具体缺口，不以改好一个次要指标宣称完成。

这是修复决策与验收方法，不保证所有生成动作能一次求解成功。它要求把可发现的返工留在交付之前，而不是交给用户发现。
